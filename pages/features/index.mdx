# 功能特性全览

## 多账号管理

- **OAuth 账号**：支持 Claude Code、ChatGPT Plus、Google Cloud OAuth
- **API Key 账号**：支持 Anthropic Console、OpenAI Platform、AI Studio
- **账号状态监控**：实时监控账号健康状态，自动处理限流和封号

## 智能调度

- **粘性会话**：基于用户 ID 和上下文内容，智能绑定会话到特定账号
- **优先级调度**：按优先级和负载自动选择最佳账号
- **自动故障转移**：请求失败时自动重试并切换账号

## 计费系统

- **精确计费**：基于 Token 计数（Input/Output/Cache）
- **灵活费率**：支持按分组设置费率倍数（如 VIP 半价）
- **使用限额**：支持日/周/月限额控制

## 其它特性

- **并发控制**：多维度的并发限制（用户级、账号级）
- **API Key 管理**：支持分组鉴权和过期时间
- **兑换码系统**：支持余额、并发数、订阅等多种兑换码
