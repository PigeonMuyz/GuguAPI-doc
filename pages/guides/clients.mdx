# 客户端代码示例

GuguAPI 完全兼容 Anthropic (Claude) 接口规范，请使用 **Anthropic SDK** 进行调用。

**Base URL**: `http://localhost:28890` (部分 SDK 会自动追加 `/v1/messages`)

<Tabs items={['Python', 'Node.js', 'Curl']}>

## Python

使用官方 `anthropic` 库。

```bash
pip install anthropic
```

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-your-guguapi-key",
    base_url="http://localhost:28890"
)

message = client.messages.create(
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude",
        }
    ],
    model="claude-3-5-sonnet-20240620",
)
print(message.content[0].text)

# 方式一：基础流式 (推荐)
# stream.text_stream 会自动处理事件，仅返回文本增量
with client.messages.stream(
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello"}],
    model="claude-3-5-sonnet-20240620",
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

print() # 换行

# 方式二：完整事件处理 (高级)
# 如果需要处理 usage 信息或监控特定事件类型
with client.messages.stream(
    max_tokens=1024,
    messages=[{"role": "user", "content": "Write a long poem"}],
    model="claude-3-5-sonnet-20240620",
) as stream:
    for event in stream:
        # 处理文本块增量
        if event.type == "content_block_delta" and event.delta.type == "text_delta":
            print(event.delta.text, end="", flush=True)
        # 处理消息结束，获取 token 消耗
        elif event.type == "message_stop":
            print(f"\n\nDone! (Input tokens: {stream.get_final_message().usage.input_tokens})")
```

## Node.js / TypeScript

使用官方 `@anthropic-ai/sdk` 包。

```bash
npm install @anthropic-ai/sdk
```

```typescript
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  apiKey: 'sk-your-guguapi-key',
  baseURL: 'http://localhost:28890',
});

async function main() {
  const msg = await anthropic.messages.create({
    model: "gpt-4o", // 支持跨模型调用
    max_tokens: 1024,
    messages: [{ role: "user", content: "Hello!" }],
  });
  console.log(msg.content);

  // 流式调用 (Streaming)
  console.log('--- Streaming Output ---');
  const stream = await anthropic.messages.stream({
    model: "claude-3-5-sonnet-20240620",
    max_tokens: 1024,
    messages: [{ role: "user", "content": "Hello" }],
  });

  // 处理流式事件
  for await (const event of stream) {
    if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
      process.stdout.write(event.delta.text);
    }
  }
  
  // 获取最终完整消息（包含 usage）
  const finalMessage = await stream.finalMessage();
  console.log(`\n\nFinished. Input tokens: ${finalMessage.usage.input_tokens}`);
}

main().catch(console.error);
```

## Curl

直接调用 `/v1/messages` 接口。

```bash
curl http://localhost:28890/v1/messages \
  -H "x-api-key: sk-your-guguapi-key" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-3-5-sonnet-20240620",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "Hello, world"}
    ]
  }'
```
