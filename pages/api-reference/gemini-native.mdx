# Gemini 原生 API

`/v1beta/` 端点提供 Gemini SDK 原生格式支持。

## 请求示例

```bash
curl -X POST "https://your-domain/v1beta/models/gemini-2.5-flash:generateContent" \
  -H "x-goog-api-key: sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{"text": "Hello!"}]
    }]
  }'
```

## Claude 兼容层

<Callout type="info">
除了原生 API，你也可以使用 `/v1/messages` 端点调用 Gemini 模型。网关会自动进行格式转换。
</Callout>

```json
{
  "model": "gemini-2.5-flash",
  "messages": [
    {
      "role": "user",
      "content": "Hello!"
    }
  ]
}
```
